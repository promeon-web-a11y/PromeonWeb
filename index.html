ABOUT PROMEON WEB

Promeon Web の特徴

中小企業・個人事業主の方が、専門知識がなくても相談しやすいホームページ制作サービスです。打ち合わせから確認・修正まで、やり取りはチャット中心。経営者の方のお時間をなるべく取らずに、事業の魅力が伝わるサイトを形にします。

チャット中心で進む

Web会議の日程調整は不要です。空いた時間にチャットとヒアリングシートでご回答いただき、そのまま制作を進めます。

料金が分かりやすい

Mini・Standard・Pro の3つの基本プランをご用意。制作内容により料金は変わりますが、内容と金額をご確認いただいてからのご依頼です。

AIの速さと、人の確認

下地づくりにはAIを活用し、文章と表示は人が確認します。速さと丁寧さの両立を目指しています。

SEO / AIO / GEO

検索エンジンにもAIにも、
伝わりやすく

これからは検索エンジンだけでなく、生成AIに質問して情報を得る人が増えています。Promeon Web は、どちらから見ても内容が伝わるようにサイトを整えます。Mini・Standard・Pro のすべてに標準で含みます（追加料金なし）。

具体的に取り組むこと

  • 結論から書き、知りたいことにすぐ答える文章構成
  • 事業内容・対応範囲・料金・連絡先など、事実情報の整理と明記
  • 検索エンジンやAIが内容を理解しやすい構造への整理（構造化データなど）
  • 表示速度とスマートフォン表示の最適化

AIO/GEO対応について詳しく

※ SEO・AIO/GEOは、検索結果や生成AIでの表示・引用を保証するものではありません。内容が正しく理解されやすい状態に整えるための取り組みです。

FLOW

ご相談から納品まで、5ステップ

Web会議は不要です。チャットとヒアリングシートのやり取りで進みます。

  1. チャットで相談

    お問い合わせフォームまたは公式LINEから、作りたいサイトのイメージ・ご予算感をお知らせください。ご相談・お見積りは無料です。

  2. ヒアリングシートに回答

    お送りするヒアリングシートに、事業内容・掲載したい情報・写真素材などをご記入いただきます。

  3. 制作

    いただいた内容をもとに、AIを活用して下地をつくり、人が文章と表示を整えて制作します。

  4. 確認

    プレビュー用のURLをお渡しします。文章・写真・レイアウトをご確認ください。

  5. 修正・納品

    ご要望をふまえて修正し、問題がなければ公開・納品します。修正回数・納期の目安は、制作内容に合わせてお見積り時にご案内します。
