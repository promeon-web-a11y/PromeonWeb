ABOUT PROMEON WEB

「伝わるかどうか」で、事業の見え方は変わる

Promeon Web は、中小企業・個人事業主の方が、専門知識がなくても相談しやすいWeb制作サービスです。打ち合わせから確認・修正まで、やり取りはチャット中心。経営者の方の時間をなるべく取らずに、事業の魅力が伝わるサイトを形にします。

チャット中心で進む

Web会議の予定調整は不要です。空いた時間にチャットとヒアリングシートでご回答いただき、そのまま制作を進めます。

料金が分かりやすい

Mini・Standard・Pro の3つの基本プランをご用意。制作内容によって料金は変わりますが、最初に内容と金額を確認してからご依頼いただけます。

AIの速さと、人の確認

下地づくりにはAIを活用し、内容と表示は人が確認します。速さと丁寧さの両立を目指しています。

SEO → AIO / GEO

時代は「検索」から「AIに聞く」へ

検索エンジンで調べる → AIにたずねて答えを得る

これまで、情報を探す手段の中心は検索エンジンでした。ユーザーはキーワードを入力し、表示された一覧からサイトを選んでいました。

いま、多くの人が生成AIに直接たずねて答えを受け取っています。このとき参照・引用されるかどうかで、事業の見つけられ方は大きく変わります。

Promeon Web は、AIに見つけられ・引用されること（AIO／GEO）を前提にした構成・情報設計に取り組んでいます。Mini・Standard・Proのすべてのプランに標準で搭載しています。

AIO／GEO対応で取り組むこと

  • 結論から書く、質問に答える形の文章構成
  • 会社・サービスの事実情報（提供内容・対応範囲・連絡先）の整理と明記
  • 構造化データなど、機械が読み取りやすいマークアップ実装範囲は要確認
  • ページの表示速度とモバイル表示の最適化

AIO/GEO対応について詳しく Proプランの内容を見る

※ AIO／GEOは新しい分野であり、効果を保証するものではありません。具体的な実装項目・範囲はお見積り時に確認します（要確認）。

FLOW

ご相談から納品まで、5ステップ

Web会議は不要です。チャットとヒアリングシートのやり取りで進みます。

  1. 1. チャットで相談

    お問い合わせフォームまたは公式LINEから、作りたいサイトのイメージ・ご予算感をお知らせください。ご相談・お見積りは無料です。

  2. 2. ヒアリングシートに回答

    お送りするヒアリングシートに、事業内容・掲載したい情報・写真素材などをご記入いただきます。

  3. 3. 制作

    いただいた内容をもとに、AIを活用して下地をつくり、人が内容と表示を整えて制作します。

  4. 4. 確認

    プレビュー用のURLをお渡しします。文章・写真・レイアウトをご確認ください。

  5. 5. 修正・納品

    ご要望をふまえて修正し、問題がなければ公開・納品します。修正回数・納期の目安は制作内容により異なります（要確認）。
