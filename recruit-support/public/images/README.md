# 画像アセットの置き場所

`src/config.js` が参照するパスに合わせて、このフォルダに実画像を配置してください。
配置前は各セクションが自動でグラデーションのプレースホルダーにフォールバックします。

| ファイル名（推奨） | 用途 | 目安サイズ |
| --- | --- | --- |
| `hero.jpg` / `hero.webp` | ①ファーストビュー背景 | 2000×1200 以上、横長 |
| `team-01.jpg` … `team-03.jpg`（＋ `.webp`） | ⑧代表・チームの顔写真 | 800×1000（4:5 縦） |
| `cta.jpg` / `cta.webp` | ⑩最終CTA背景 | 2000×1000 以上 |
| `og.jpg` | OGP画像 | 1200×630 |

## 最適化の指針
- WebP を併記（`<picture>` の `<source type="image/webp">` で自動切り替え）
- ヒーロー以外は `loading="lazy"` 済み。ヒーローは LCP のため `fetchpriority="high"`
- 書き出し時に長辺を必要サイズまで縮小し、JPEG 品質 75〜82 目安
