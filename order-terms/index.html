Webサイト制作申込規約

制定日：準備中（サイト公開時に確定）

本規約は、Webサイト制作のお申し込みにあたり適用される事項を定めるものです。本規約に定めのない事項は、Promeon Web サービス利用規約その他の規約によります。

1. 個別契約の内容

見積書又は申込確認書等で以下を定めます。

  • 制作プラン
  • Webサイトの目的
  • ページ数又はセクション数
  • デザイン
  • 機能
  • 制作料金
  • オプション料金
  • 支払方法
  • 支払期限
  • 制作開始予定
  • 納期
  • 修正回数
  • 納品方法
  • サーバー・ドメイン
  • 保守契約
  • その他個別条件

個別契約と本規約が異なる場合は、個別に合意した内容を優先してください。

2. 制作開始

以下の条件が整った後に制作開始とします。

  1. ヒアリング完了
  2. 必要情報・素材の提供
  3. 見積内容・制作条件への合意
  4. 指定された支払条件の完了

3. 仕様変更

制作開始後に当初の制作内容を超える変更を希望する場合、追加料金又は納期変更が発生する場合があります。

4. 修正

契約したプラン又は見積書記載の回数まで修正を行います。

軽微な修正と、大幅な仕様変更は区別します。

5. 納品及び確認

制作完了後、顧客に確認を依頼し、双方が合意した修正完了後に納品又は公開します。

6. 納品後

納品後の追加修正、更新、保守、サーバー管理等は、契約に含まれる場合を除いて別途料金とします。

7. キャンセル

制作開始後に依頼者都合で終了する場合、その時点までに実施した作業及び実費等について精算します。

8. 契約解除

以下の場合、改善を求めた上で契約解除する場合があります。

  • 必要情報が長期間提供されない
  • 支払期限を経過しても支払いがない
  • 違法サイトの制作依頼
  • 第三者の権利侵害を伴う制作依頼
  • その他重大な規約違反

9. 他規約との関係

本規約に定めのない事項は、

  • Promeon Web サービス利用規約
  • プライバシーポリシー
  • 特定商取引法に基づく表記
  • 個別見積書・契約内容

を適用します。
