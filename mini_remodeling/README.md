# 北海リフォーム株式会社（Miniプラン サンプルサイト）

Promeonの「Miniプラン」の完成イメージを示すための、架空のリフォーム会社の
1ページ完結型サンプルサイトです。会社名・住所・電話番号・写真はすべて
**架空の内容**です。実在する企業・人物とは一切関係ありません。

---

## 1. ファイル構成

```
mini_remodeling/
├─ index.html          … サイト本体（1ページ・全6セクション）
├─ css/
│   └─ style.css         … デザイン（配色・フォント・レイアウト・レスポンシブ）
├─ public/
│   └─ images/           … サイトで使う写真専用フォルダ（差し替え用）
│       ├─ hero.png          … ファーストビューの背景写真
│       ├─ service-interior.png … 内装リフォームの写真
│       ├─ service-exterior.png … 外壁リフォームの写真
│       ├─ service-roof.png     … 屋根修理の写真
│       ├─ service-water.png    … 水回りリフォームの写真
│       └─ company.png       … 会社情報欄の写真
└─ README.md             … このファイル
```

HTML・CSSのみのシンプルな構成です（JavaScriptなし）。ビルドツールや
フレームワーク、外部の有料APIは一切使用していません。

写真はすべて `public/images/` フォルダにまとめてあります。詳しい差し替え方法は
「4. 画像の差し替え方法」を参照してください。

---

## 2. 起動方法（確認方法）

インストール作業は不要です。

1. `index.html` をダブルクリックしてブラウザで開く
   → これだけで表示の確認ができます。

より実際のWeb環境に近い状態で確認したい場合は、簡易サーバーを使う方法もあります（任意）。

```bash
cd mini_remodeling
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

スマートフォン表示は、ブラウザの開発者ツール（F12キー→デバイスツールバー）で
確認できます。

## 4. 画像の差し替え方法（画像管理について）

サイトで使う写真は、すべて **`public/images/` フォルダ** の中に集めてあります。
現時点では本物の写真がまだないため、青とターコイズを使った「仮の画像
（プレースホルダー）」を設定しています。フォルダ内のPNGファイルを見れば、
サイトのどこにどんな写真が入るのか一目で分かるよう、用途がそのまま伝わる
ファイル名に統一しています。

### 画像一覧

| ファイル名 | 表示される場所 | 推奨サイズ（横×縦） | 縦横比の目安 |
|---|---|---|---|
| `public/images/hero.png` | ①ファーストビューの背景写真 | 1600×900px程度 | 16:9（横長） |
| `public/images/service-interior.png` | ②サービス「内装リフォーム」の写真 | 800×600px程度 | 4:3 |
| `public/images/service-exterior.png` | ②サービス「外壁リフォーム」の写真 | 800×600px程度 | 4:3 |
| `public/images/service-roof.png` | ②サービス「屋根修理」の写真 | 800×600px程度 | 4:3 |
| `public/images/service-water.png` | ②サービス「水回りリフォーム」の写真 | 800×600px程度 | 4:3 |
| `public/images/company.png` | ⑤会社情報欄の施工風景・スタッフ写真 | 800×600px程度 | 4:3 |

### 差し替え手順（初心者向け）

1. `public/images/` フォルダを開く
2. 差し替えたい写真と**同じファイル名**（例：`hero.png`）で、実際の写真を
   上書き保存する
3. `index.html` は一切編集しなくてOKです。ファイル名が同じであれば、
   ブラウザで開いたときに自動的に新しい写真に置き換わります

これが実現できているのは、`index.html` 側が常に `public/images/ファイル名.png`
という決まったパスを見に行くようにしてあるためです。画像の中身を差し替えても
参照先のパスは変わらないので、コードの修正は不要です。

### 拡張子について（.jpg や .webp の実写真を使いたい場合）

プレースホルダーは、ビルドツールなどを使わずに作成できる **PNG形式**
（`.png`）で用意しています。実際の写真も多くの画像編集ソフト・スマホの
写真アプリで「PNG形式で保存」を選べば、拡張子を変えずにそのまま同じ手順
（ファイル名を合わせて上書きするだけ）で差し替えられます。

`.jpg` や `.webp` など別の形式のまま使いたい場合は、上書きではなく
「同じ名前部分＋新しい拡張子」（例：`hero.jpg`）で保存したうえで、
`index.html` 内の該当する `<img src="public/images/hero.png" ...>` の
`.png` の部分だけ、使いたい拡張子に書き換えてください（1行の修正だけで
済みます）。

## 5. お問い合わせについて（重要）

このサンプルには実際の送信処理はありません。「電話で相談する」ボタンは`tel:`リンク、
「お問い合わせ」ボタンは`mailto:`のダミーリンクです。

実際に運用する際は、フォーム送信サービスの導入や、サーバーサイドの送信処理の追加を
検討してください（Standard／Proプランで対応可能です）。

## 6. デザインについて

- ベースカラー：白（`css/style.css` 内 `--color-bg` など）
- メインカラー：爽やかなブルー（見出し・ボタン・アイコン用、`--color-primary`）
- アクセントカラー：ターコイズ（CTA・ホバー・小さなアクセント用、`--color-turquoise`）
- 文字色：濃いネイビー／濃いグレー（`--color-navy` / `--color-text`）
- スマートフォンでは画面下部に「電話」「お問い合わせ」ボタンを固定表示し、
  問い合わせ導線を最優先にしています

会社カラーを変更したい場合は、`css/style.css` 冒頭の `:root { ... }` 内の
色コードを変更するだけで、サイト全体の配色が変わります。

---

## 7. Miniプランとしての位置づけ

このサイトはStandard／Proプランではなく、Miniプランのサンプルです。
そのため、ブログ・お知らせ管理・会員登録・複雑な予約システム・CMS・
大量の施工事例・EC機能・下層ページなどは含んでいません。1ページで完結する、
情報量を絞ったシンプルな構成にしています。

---

## 8. 注意事項

- 本テンプレートに含まれる会社名・住所・電話番号・写真プレースホルダーは、
  **すべて架空のサンプル**です。
- 実際の会社で利用する際は、必ず正しい情報に差し替えたうえで公開してください。
